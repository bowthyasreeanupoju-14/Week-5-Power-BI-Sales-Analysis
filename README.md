# Week 5 – Power BI Sales Performance Analysis

## 📊 Project Overview

This project focuses on analyzing sales data using Microsoft Power BI.
The analysis includes data preparation, data modeling, DAX measures,
visualizations, interactive filters, and business insights.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel

## 📌 Tasks Completed

### Task 1 – Data Import
Imported the required sales-related datasets into Power BI.

### Task 2 – Data Cleaning & Preparation
Prepared the sales data using Power Query and verified data types,
errors, and missing values.

### Task 3 – Data Modeling & Relationships
Created relationships between the Sales table and supporting tables
such as Customer, Product, Date, Reseller, Sales Territory and Sales Order.

### Task 4 – DAX Measures

Created the following measures:

- Total Sales
- Average Sales
- Total Records
- Maximum Sales
- Minimum Sales

### Task 5 – Power BI Visualizations

Created visualizations including:

- Total Sales by Product Name
- Sales Distribution by Category
- Total Sales by Product Category
- Top 10 Product Subcategories by Sales
- Product Name and Total Sales table

### Task 6 – Interactive Dashboard

Created an interactive **Sales Performance Dashboard** containing
KPI cards, charts, a product table, Category slicer and Product Name slicer.

### Task 7 – Business Insights

The analysis identified Bikes as the strongest-performing category,
with Road Bikes and Mountain Bikes being major contributors to sales.
Lower-performing categories such as Accessories and Clothing were
identified as opportunities for improvement.

## 📈 Key Results

- Total Sales: approximately ₹109.81M
- Average Sales: approximately ₹905.62
- Total Records: approximately 121K
- Highest-performing category: Bikes
- Highest-performing subcategory: Road Bikes
